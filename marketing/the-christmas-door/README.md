# The Christmas Door

The collection lives at [thomasbroadside.co/Christmas](https://thomasbroadside.co/Christmas/). Open `index.html` here for the offline campaign kit, or start with `START-HERE.txt`. The assets are ready for the shop to distribute; installing the collection does not send a campaign.

The public entry point is `site/Christmas/index.html`. It uses the existing house fonts and a scoped stylesheet and script. Public previews and the web film are in `site/media/christmas/`. The wide and single layouts are separate illustrations. Scenes show the designs in context; they are not photographs of manufactured or installed goods.

The quote link opens the same public intake form as [Thomas Graphics](https://tgatx.com/). It prefills the project name, Signs & spaces category, quantity, and project brief. The brief includes the selected layout, any measured dimensions, and incoming campaign tags. Only the visitor's submission on that form creates an inquiry. No contact information, money or order is collected by this page. If the form is replaced, update its public action and field IDs together, then confirm them using a prefilled read-only visit.

Production is by fitted quote. Use the separately supplied editable printer kit, measured door layout, approved attachment plan and fitted color proof before fabrication. The existing broadside checkout, shipping rules, and catalogue prices do not apply to these covers.
